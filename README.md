# Sobre o Projeto

RotaBus é um sistema de consulta de passagens de ônibus, desenvolvido para a A3 da UC de Sistemas Distribuídos e Mobile.

O sistema permite consultar viagens disponíveis, visualizar origem, destino, horário e valor da passagem. Também possui uma área administrativa para gerenciamento de viagens, empresas e usuários.

## Pré-requisitos

- IntelliJ IDEA
- Java JDK 21 ou superior
- Maven

## Instalação e utilização

1. Clone o repositório com ```git clone https://github.com/eduardo-ft-maia/A3-sistemas-distribuidos-e-mobile```
2. Abra o projeto no IntelliJ
3. Aguarde o Maven baixar as dependências automaticamente
4. Rode a classe principal ```RotabusApplication.java```
5. Acesse no navegador ```http://localhost:8080```
6. Login teste de administrador
```text
Usuário: admin
Senha: 123
```
7. Login teste de empresa
```text
Usuário: empresa1
Senha: 123
```
8. Acesso ao banco H2
```bash
http://localhost:8080/h2-console
jdbc:h2:mem:rotabusdb
```
